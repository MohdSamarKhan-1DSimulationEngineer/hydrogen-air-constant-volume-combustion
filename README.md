Hydrogen-Air Constant-Volume Combustion Model

1. Project Overview

This project focuses on developing a zero-dimensional model of hydrogen-air combustion in a constant-volume combustion chamber using MATLAB/Simulink.

The model is intended to investigate combustion behavior through thermodynamic calculations, chemical kinetics, species conservation, and numerical simulation.

2. Research Objectives

- Develop a zero-dimensional hydrogen-air combustion model.
- Implement thermodynamic properties using NASA-7 polynomial data.
- Model hydrogen-air chemical reaction kinetics.
- Validate species mass fractions and elemental conservation.
- Investigate temperature and pressure evolution.
- Analyze heat-release rate and ignition behavior.
- Extend the model to investigate heat transfer to the chamber walls.

3. Model Configuration

- Combustion system: Constant-volume chamber
- Working mixture: Hydrogen and air
- Initial pressure: 1 bar
- Initial temperature: 1000 K
- Equivalence ratio: 1
- Modeling environment: MATLAB/Simulink
- Thermodynamic approach: NASA-7 polynomials

These are the current baseline conditions for the project and may be modified for subsequent studies.

4. Model Development Status

The current development stage includes species mass-fraction validation.

Further work will focus on additional numerical verification, energy conservation, ignition-delay analysis, heat-release calculations, and comparison against suitable reference data.

5. Planned Results

- Temperature versus time
- Pressure versus time
- Species mass fractions versus time
- Heat-release rate versus time
- Species and elemental conservation errors
- Sensitivity to initial conditions

6. Software

- MATLAB
- Simulink

The exact MATLAB release and any additional software dependencies will be documented as the project develops.

7. Research Scope

The long-term objective is to establish a reproducible simulation framework suitable for investigating hydrogen combustion in a constant-volume system.

8. Current Limitations

Results, validation metrics, and physical predictions will be documented after the corresponding simulations and verification studies have been completed.
